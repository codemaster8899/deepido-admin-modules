# Deepido Admin — Selected Modules

Selected **Vue admin** modules for Deepido: routes plus Pinia/Vuex-style stores and views for clients, contacts, devices, music, playlists, spots, tickets, users, and metrics.

> Frontend admin slice from a larger venue / music operations product.

## What’s included

| Area | Role |
|------|------|
| `routes.js` | Vue Router map under `/{locale}admin` |
| `stores/` | Client, contact, device, music, playlist, spot, user, tags, errors |
| `views/` | CRUD screens and modals for the domains above (tickets, metrics, …) |

### Domains covered

Users, clients, contacts, devices, music library, playlists (+ history), spots (+ tags), tickets, metrics (players / syncs / users)

## Tech stack

Vue 3, Vue Router, Pinia/store modules, admin UI views
